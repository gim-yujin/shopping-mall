## 5) 관찰된 주요 패턴

- 대부분 시나리오에서 **TTFB(서버 응답 대기)가 전체 지연의 거의 전부**를 차지
- p99가 **60초로 고정되는 구간**이 다수 존재(클라이언트/요청 타임아웃으로 추정)
- 인증이 필요한 경로에서 **/auth/login 리다이렉트(미인증 처리)**가 폭증

## 6) 개선 우선순위(요약)

### P0 (즉시)
- 핵심 쿼리 경로 인덱스 복구/최적화(홈, 상품목록/상세, 주문목록, 사용자 조회)
- browse 트래픽이 checkout/order를 잠식하지 않도록 격리(풀 분리/리드 레플리카/로드셰딩)

### P1 (단기)
- 로그인/세션 경로 안정화(세션 저장소/리다이렉트 체인/CSRF 처리 점검)
- 쿠폰러시 시나리오에서 사전 로그인 상태(또는 토큰) 기반으로 쿠폰 API 자체를 재측정

### P2 (중기)
- arrival-rate 기반 부하(고정 RPS)로 용량 측정/브레이킹 포인트 탐색
- 서버/DB APM + 슬로우쿼리/플랜(EXPLAIN) 수집을 자동화하여 원인-증상 매핑
